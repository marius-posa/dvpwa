Issues to fix:

### CQLF-R18-0001: js/xss-through-dom (js/xss-through-dom)
- Severity: HIGH (7.8)
- CWE: cwe-79, cwe-116
- Location(s): sqli/static/js/materialize.js:2850
- Description: [DOM text](1) is reinterpreted as HTML without escaping meta-characters.
- Rule: DOM text reinterpreted as HTML
- Guidance: # DOM text reinterpreted as HTML
Extracting text from a DOM node and interpreting it as HTML can lead to a cross-site scripting vulnerability.

A webpage with this vulnerability reads text from the DOM, and afterwards adds the text as HTML to the DOM. Using text from the DOM as HTML effectively unescapes the text, and thereby invalidates any escaping done on the text. If an attacker is able to control the safe sanitized text, then this vulnerability can be exploited to perform a cross-site scrip
